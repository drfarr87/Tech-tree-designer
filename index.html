Controls

The workspace is 10× larger in both directions for long-term tree growth. Drag nodes to arrange them. Shift-click nodes to add/remove them from a multi-selection; drag any selected node to move the whole group. Shift-drag empty canvas to box-select multiple nodes. A normal click on empty canvas clears the selection. Mouse-wheel or pinch to zoom. Click Connect for prerequisite → dependent, Connect Upgrade for old unit → upgraded unit, or Connect Replacement for old production unit → replacement. Dashed arrowed lines show unit upgrade paths. Use Epoch Manager to add, rename, reorder, position, or remove epochs. You can also drag an epoch label vertically to move its full-width horizontal boundary; node epochs update automatically from position. Branch colors are editable. Use the search box to highlight matching node names; press Enter or Search to zoom to and select the best match. Repository JSON is the shared baseline. Browser edits autosave locally; Export Snapshot creates the file to commit back to GitHub.
